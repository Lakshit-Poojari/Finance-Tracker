#  Finance Tracker Dashboard

A modern and interactive financial dashboard built using React that helps users track income, expenses, and overall balance with powerful visual insights.

---

##  Tech Stack

*  React (Vite)
*  React Bootstrap + Bootstrap 5
*  Recharts (Charts & Data Visualization)
*  React Icons
*  React Router DOM
*  Context API (State Management)
*  LocalStorage (Data Persistence)

---

##  Features

###  Dashboard

* Displays Total Balance, Income, and Expenses
* Clean summary cards for quick insights

###  Charts & Analytics

* Line Chart for balance trends
* Pie Chart for expense distribution

###  Transactions Management

* Add, edit, and delete transactions
* Organized transaction listing

###  Search & Filters

* Search transactions by keyword
* Filter by type (Income/Expense)
* Filter by category

###  Role-Based Access

* Admin → Full control (Add/Edit/Delete)
* User → View-only access

###  UI Features

* Responsive design using Bootstrap
* Theme toggle (Light/Dark mode)

###  Persistence

* Data stored in LocalStorage
* No data loss on refresh

---

##  Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/Lakshit-Poojari/Finance-Tracker.git
```

2. Navigate to the project:

```bash
cd finance-tracker
```

3. Install dependencies:

```bash
npm install
```

4. Run the development server:

```bash
npm run dev
```
